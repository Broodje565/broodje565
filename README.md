## 🚀 Featured Project

### 🎨 [Smartschool++ (SMPP)](https://github.com/sprksoft/smpp): *Developer Coordinator*

> A browser extension that supercharges **Smartschool**, the learning platform used by Belgian schools, with themes, widgets, games and more.

* **~20,000 users** on the Chrome Web Store
* Also available for **Firefox**
* **Manifest V3 · TypeScript**
* Privacy-first: only storage permission, with no data collection
* **30+ themes**, custom backgrounds and shareable theme links
* Draggable widget dashboard with:

  * Planner
  * Next course
  * Tasks & grades
  * Notes
  * Countdowns
  * Weather
  * Virtual plant
* Quick Menu (`:`) for fast navigation
